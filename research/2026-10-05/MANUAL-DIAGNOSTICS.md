# 人工救援逻辑清退

2026-10-05。当前源码与离线包将 `rescue` 收窄为 `status`、`verify`、`log`、`help`。删除直接 `lvchange --refresh` 的人工封装，保留 F9/F10 的密码认证、完整 root shell、系统工具与 RAM 日志。自动恢复仍由现有 C++ Guard 负责。

## 实现

- 删除旧刷新方法、LV 目标参数、确认输入、重复切换检查、旧实验 RPC 及专用 LVM 段报告夹具。
- 共享只读接口改名为 `RescueDiagnostics`，冷态登记继续复用 USB/PV/VG 核验和 LV 依赖查询。保留只读身份核验，未把它误当作废弃恢复代码删除。
- `help`、`log` 不再依赖身份文件；未登记环境中的 `status` 返回明确诊断。已退役命令在解析参数阶段拒绝，尚未读取身份或调用设备工具。
- 登录提示统一由当前会话打包逻辑覆盖并记录散列。保护 initrd 与数据维护离线包即使复用旧通用 base，也会覆盖当前诊断脚本和提示，避免旧代码被重新打入产物。
- 当前 `lab/run.py` 删除旧人工恢复主流程，只保留其他实验使用的 QEMU 辅助接口；直接执行该历史场景时委托完整的固定 Git 快照。C++ 事务观察器对其冻结依赖的旧类名只在临时实验目录适配，生产代码不保留兼容别名。

普通回退启动的新工具包也不再提供 `rescue refresh`，但它不会因此获得自动根盘保护。root shell 仍有管理员权限和系统工具；本次删除的是项目的写操作封装，不是建立受限 shell 或阻止已认证管理员操作设备。
